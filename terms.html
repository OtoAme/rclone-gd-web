服务条款

版本号：1.0
生效日期：2026-10-23

Local Drive Sync 是个人 OAuth 客户端的名称。实际搬移文件的程序是使用者自己安装的 rclone。

一、应用信息

  • 应用名称：Local Drive Sync
  • 首页：https://nav.otoame.top/rclone-gd-web/
  • 隐私权政策：https://nav.otoame.top/rclone-gd-web/privacy.html
  • 用途：在自己的电脑上访问自己的 Google 云端硬盘

二、使用范围

这个客户端供创建它的开发者本人使用，不是面向公众的同步服务。请只授权自己有权使用的 Google 账号。请不要公开客户端密钥。

三、停止使用

使用者可以在 Google 账号的第三方访问权限里撤销 Local Drive Sync，并删除自己电脑上的 rclone 配置。

四、其他

本网站不提供托管存储，也不保证 rclone 或 Google API 不中断。使用 Google API 时，仍受 Google 自己的条款约束。Local Drive Sync 与 Google、rclone 项目均无隶属关系。
